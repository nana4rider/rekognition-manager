# ADR 0001: WebとBFFを別プロセスにする

- ステータス: 採用
- 日付: 2026-07-16

## 背景

Rekognition ManagerはNext.jsの管理画面と、AWS Rekognitionを操作するBFFから構成される。
将来はOIDC認証をBFFパターンで追加する予定がある。

## 決定

- Next.jsとHono BFFは同じnpm workspacesリポジトリで管理する。
- 開発時とコンテナ実行時は別プロセスにする。
- ブラウザには同一オリジンとして公開し、`/api`と`/auth`をBFFへ転送する。
- AWS SDKとAWS認証情報はBFFにだけ配置する。
- BFFではHTTP層、アプリケーション層、インフラストラクチャ層を分離する。

## 理由

- AWS操作と画面表示の責務を分離できる。
- AWS認証情報をブラウザへ公開せずに済む。
- 将来のOIDCトークンとセッション管理をBFFへ集約できる。
- WebとBFFを独立してテスト、デバッグ、デプロイできる。

## 影響

- ローカルでは2プロセスを起動する必要があるが、`npm run dev`でまとめて起動する。
- 本番ではリバースプロキシまたはNext.jsのrewritesが必要になる。
